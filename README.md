# 抖音精简助手（DouyinTuner）

LSPosed 模块，给 **抖音 40.7.0** 做去广告、界面精简、停上报、无水印直链、防撤回等 19 项开关，
每项都能单独关掉。改动只在运行时生效，不改抖音安装包。

- 模块包名：`com.mod.douyintuner`
- 产物：`app/build/outputs/apk/release/app-release.apk`
- 签名：`E:/huaian.jks`（别名 `huaian`，密码见 `keystore.properties`）；换过签名，装前先卸载旧版
- 图标设计稿：`icon/app-icon.png`

## 安装

1. 装 `app-release.apk`（之前装过用 `douyintuner.jks` 签的旧版，必须先卸载，否则签名冲突装不上）。
2. LSPosed 里启用「抖音精简助手」，作用域勾选 `com.ss.android.ugc.aweme`。
3. 强制停止抖音再打开（开关改动同样要重启抖音才生效）。
4. 面板里逐项开关。日志：`adb logcat -s DouyinTuner`，默认只打加载行、生效摘要行和**没生效**的行。

## 功能

| 面板开关 | 作用 |
| --- | --- |
| 后台保活清理 | 后台服务不再被互相拉起，挂久了内存也不被吃回去；推送通道不动 |
| 预加载与缓存上限 | 预加载任务收窄到 3 条，少占内存和流量 |
| 底部只留「首页/信息/我」 | 底部栏白名单，发布按钮也摘掉——要发视频先关掉这个开关 |
| 顶部只留「推荐/关注/直播」 | 顶部频道栏白名单，团购/同城/朋友等隐藏 |
| 移除侧边栏营销入口 | 摘掉侧边栏与个人页的商城/带货/营销入口 |
| 去活动弹窗与浮层 | 开屏活动弹窗、首页营销浮层不再出现 |
| 拦未成年人模式弹窗 | 青少年模式引导/切换/时长提醒弹窗一律不显示（设置里主动打开也拦，想进去先关开关） |
| 去开屏广告 | 开屏广告直接跳过，不留残影 |
| 过滤信息流广告 | 在数据源头摘除广告条目，不留空卡片 |
| 禁止升级与自更新下载 | 拦升级弹窗、禁安装包下载与安装引导；gecko/lynx 资源包热更新不受影响 |
| 无水印直链复制 | 长按视频 → 分享 → 复制链接，剪贴板里就是无水印直链（见下） |
| 闪图可反复查看 | 私信闪图/一次性查看不再变「已看过」，可以反复打开 |
| 消息防撤回 | 被撤回的消息在聊天页仍显示原文/原图 |
| 冷启动加速 | 开播放器冷启降级开关 + 摘掉定位/地图/小程序等与首帧无关的启动任务 |
| 配置覆盖（进阶） | 按 `overrides.txt` 覆盖抖音自己的 AB 配置项，改完重启抖音 |
| 停埋点上报 | 事件强制上报直接拦掉，不再出网 |
| 禁用热修 | 抖音不再后台静默热修（线上修复也会失效，出怪问题先关它） |
| 红点静默 | 角标/红点不再刷新（推送消息本身保留） |
| 隐藏桌面图标 | 隐藏模块在桌面的图标；隐藏后从 LSPosed 模块列表长按模块 →「模块设置」进面板 |

### 无水印直链怎么用

模块编译期拿不到抖音的类，也没法给长按面板塞自定义条目，所以做成对用户等价的一步：

**分享（长按视频没有分享入口时用视频右侧的分享控件）→ 复制链接 → 剪贴板里落下来的就是无水印直链**
（原短链被替换，分享文案保留）。成功会弹一次 Toast「抖音精简助手：已把分享链接换成无水印直链」。

只在文本里出现 `douyin.com`/`iesdouyin.com` 时才动手，复制纯文案、口令不受影响。
复制名片、主页、直播间分享也原样放过。

### 冷启动加速做了什么、没做什么

- **播放器降级开关**：抖音有一批「冷启降级」实验值（预加载管理器、视频效果/插件、亮度、音量平衡等），
  按 key 强制走省流程分支。这些 key 不认「配置覆盖」里写法，要单独改哪一项就在 `overrides.txt` 里写
  `cold_boot_xxx_yyy=1` / `=0` 覆写内置白名单。
- **摘掉的启动任务**：定位管理器、冷启定位、小程序初始化、地图初始化、锁优化共 5 个与首页首帧无关的任务。
- **故意不动的**：播放器内核初始化（跳了视频播不了）、首页布局 inflate、服务解析基座、崩溃兜底、
  登录/网络/埋点，以及所有首帧之后才跑的收尾任务。
- 限制：抖音改版后按类名过滤的清单会失配，日志里会打印实际经过的启动任务清单（最多 40 条），
  照日志扩表即可；`*_DEGRADE` 的语义是「true = 走省流程分支」的推断，若某个 key 反而更慢，用
  `overrides.txt` 把它写成 `0` 单独关掉。

### 消息防撤回的限制

- 撤回时的旁路清理也一并失效：@ 提及记录和全文索引不再被删（能搜到已撤回的原文，副作用是数据库里多留几条索引）。
- 会话列表里的「撤回了一条消息」预览可能仍然显示（列表和聊天页走的是两套判断），点进聊天页是原文。
- 图片/视频仍依赖 CDN 存活：撤回前没缓存过、且服务端已失效地址的媒体会加载失败，文字 100% 保留。

### 闪图（一次性查看）的限制

- 闪图图片不加密：可以反复看，也可以截图。
- 闪图视频是 DRM 的：只保证能反复打开，不保证能导出文件（抖音自己也会拦「不允许下载」）。

### 配置覆盖表

路径：`/data/data/com.mod.douyintuner/files/overrides.txt`（面板里点「配置覆盖表」会生成模板并复制路径）。
每行 `key=value`，`#` 注释。key 是抖音自己的 AB 键名，写错或不存在时该项不生效、不影响运行。改完要重启抖音。

```
player_setting_enable_ab_cache=false
```

登录、风控相关 key 不要往里加。

## 构建

```bash
export JAVA_HOME="E:\\JAVA\\20"
./gradlew :app:assembleRelease
```

签名用 `E:/huaian.jks`（别名 `huaian`），凭据在 `keystore.properties`；要换回自签就改回
`keystore/douyintuner.jks`，keystore 丢了可以重新生成：

```bash
"E:/JAVA/20/bin/keytool.exe" -genkeypair -v -keystore keystore/douyintuner.jks \
  -storetype PKCS12 -keyalg RSA -keysize 2048 -validity 10000 -alias douyintuner \
  -storepass dy123456 -keypass dy123456 -dname "CN=DouyinTuner,OU=mod,O=mod,L=Beijing,ST=Beijing,C=CN"
```

## 真机验证清单

装好后强制停止抖音再打开，`adb logcat -s DouyinTuner` 先看两行：

```
==== 抖音精简助手加载 com.ss.android.ugc.aweme v40.7.0（针对 40.7.0 编写，缺项会自动跳过）
==== 已挂钩 18 项：后台保活清理、预加载与缓存上限、…（有跳过/异常行说明那几项没生效）
```

默认只打这三类：加载行、生效摘要行，以及**没生效**的行（类不存在 / 方法不匹配 / 挂钩异常）。
任何「没生效」的行都说明该点在你这台机器上没起作用，把那一行发回来即可。

| # | 操作 | 期望 |
| --- | --- | --- |
| 1 | 冷启动抖音 | 无开屏广告 |
| 2 | 看首页底部 tab | 只剩首页/信息/我，发布按钮也没了 |
| 3 | 看首页顶部频道栏 | 只剩推荐/关注/直播 |
| 4 | 刷 20 条首页 | 无广告卡片、无空位 |
| 5 | 分享 → 复制链接 | 粘贴出来是 `.../play/...` 直链，分享文案保留，弹一次成功 Toast |
| 6 | 挂在后台 10 分钟 | 内存不被后台服务吃回去 |
| 7 | 等红点 | 抖音图标无角标 |
| 8 | 设置里点「检查更新」 | 无升级弹窗 |
| 9 | 触发青少年模式提醒 | 弹窗不出现 |
| 10 | 私信收到闪图，查看后退出再进 | 还能再打开 |
| 11 | 让对方撤回一条文字消息 | 聊天页仍显示原文 |
| 12 | 冷启动看日志 | 有「已挂钩 18 项」，以及实际经过的启动任务清单（据此可扩充跳过表） |

失败最常见原因：抖音版本不是 40.7.0（看日志里的 `v` 号）、LSPosed 作用域没勾、开关改完没重启抖音。

## 已知限制

- 只在抖音 **40.7.0** 上做过验证；换版本可能大面积失效（日志里会是一堆「没生效」的行）。
- 底部/顶部 tab 白名单按抖音下发的 id 字符串匹配：抖音改版换了 id 就会失配，
  每次启动会把两份原始 id 列表各记一次日志，照日志改白名单即可。
- 直播频道的 id 查不到（只有事件名），顶部白名单按关键字兜底。
- 无水印直链依赖「当前有一个正在看的视频」：从消息里复制自己发过的作品、或没进过长按/分享面板就复制，
  会改写失败——此时日志打出原文，方便定位。
- 信息流源头过滤会改变列表长度；某个版本刷流出现错位就先关「过滤信息流广告」。
- 停埋点上报只拦了事件强制上报，APM 底层网络发送没动（那里返回值被上游直接用，拦掉容易崩）。
- 隐藏桌面图标之后进面板：从 LSPosed 模块列表长按模块 →「模块设置」；万一某个 LSPosed 版本不认，
  用 `adb shell am start -n com.mod.douyintuner/.MainActivity`，或
  `adb shell pm enable com.mod.douyintuner/com.mod.douyintuner.Launcher` 把图标启用回来。
- 设备指纹、风控滑块（`bdturing`）、Web 容器安全（`ies/argus`）、账号与支付相关一律没碰。
- 直播相关没做（按需求保留原样）。
